# HackClub WrongTool event: Floor is Lava escape room in Terminal
## About
My name's Winston (though I go by the user winwon230 on slack and git), and I started making this game as part of HackClub's WrongTool event, which is basically where you make a game in something that isn't a game.
I've played my fair share of escape room games (embarassingly mainly on Roblox), and I thought it would be really cool if I could make my own, but have one that is properly difficult.
The game has taken ~10 hrs to make, and was logged in Hackatime, and I'm really proud of how I've extended my vague past Python knowledge to build the game.
## Lore
The character you're assigned as in the game seemingly is genderless and tbh, we never really get to know much about him/her/it.
Initially, what I meant for the character was this:
- I wanted the character to be some kind of morally ambiguous figure, bc in some ways it could be a psychotic patient, hence the weird white-eyed characters it observes and the fact it hardly speaks.
- The lava almost acts like an afterthought, but with a max level of 5, it is very much dangerous in the first two rooms, and provides a bit of pressure to players to not make mistakes
- The clock really could symbolise anything, in some forms it's kinda a recall to some kind of traumatic event for the character, which is why it always causes these perculiar events when it activates
- The ambiguous ending and the conquest through these rooms just to reach some kind of light is a questioning of the meaning of life itself, and I wanted players to think about what effect their actions really have on the world
## How to play/download
I should've put this earlier lol.
1. Download the game.py file off of my Github Repo
2. If you're using a Mac (which I made this game on):
    1. Open a terminal
    2. Type `python3 --version`
    3. If a Python version pops up, ur good. Otherwise, go to python.org and download Python
    4. Type `cd `(including the space), and drag the folder name of wherever you downloaded the game to from Finder into terminal, then press enter.
    5. Run this command: `python3 game.py`
3. If you're using Windows:
    1. Open a terminal (which apparently called Command Prompt on Windows lol)
    2. Type `python -- version`
    3. If a Python version pops up, ur good. Otherwise, go to python.org and download Python
    4. Open the folder where you downloaded the game onto, click the address bar, copy the folder path, and then in command prompt type `cd ` (including the space) and paste the path, and press enter 
    5. Run this command: `python game.py`
4. You're prompted at the beginning of each 'turn' (ig if that's what you want to call it), and you simply answer with a number or a sequence of numbers which tell you what you can do
## Cheat code if you're stuck
- *The clock is important, it tells you how many turns you are away from a monster coming*
- First room's easy, go 3, then 2, then 1,
- For the second room:
    - You need to open the red door and solve the snake puzzle. The answer is 3 bc 1 and 2 contradict each other.
    - You then open the blue door and give the code 483
    - If you did the wrong one on the red door, you need to rush back into the original room, check the clock and hide in the cabinet
- For the third room:
    - I'm super proud of the puzzle which I thought of myself without other game inspiration, basically you use George and Goober's accounts to figure out that George needs antibiotics and Goober needs the popsicle
    - You need to talk to the guard, who says 'Protocol One Twenty', which the initials spell 'POT'
    - You then need to use the clothes given to you to form 'POT' from top to bottom, so the Polar fleeced hat, the Orange T-shirt, and the Threaded Trousers
    - The guard then allows you to go through, and you run straight to the elevator and you win, **do not panic and look for a hiding spot in this final sequence**
